# 🩸 Blood Requirement & Donor Matching System

A simple **C Programming mini project** that helps search sample donor records based on blood group, location, and required units.

## 🌐 Live Demo

👉 **[Open Blood Requirement & Donor Matching System](https://shivshankar28082008-rgb.github.io/Blood-Requirement-Donor-Matching-System-/)**

## ✨ Features

- 🩸 Select required blood group
- 📍 Enter location
- 🔢 Enter required blood units
- 🔎 Find matching donor records
- 👥 View donor list
- 📋 View blood requirement requests
- ✅ Matching result display
- 📱 Responsive browser interface

## 🔄 How It Works

**Blood Requirement → Blood Group + Location + Units → Search Donors → Display Matching Records**

The demo matches records using:

**Same Blood Group + Matching Location + Sufficient Available Units**
